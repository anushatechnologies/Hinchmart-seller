1. ADMIN PRODUCT MODERATION & APPROVAL APIS (FOR ADMIN)
================================================================================

1.1 List All Pending Products for Review
--------------------------------------------------------------------------------
Method: GET
URL: https://api.hinchmart.com/api/admin/products/pending
(or GET /api/admin/products?status=PENDING)
Headers:
  Authorization: Bearer <ADMIN_JWT_TOKEN>

Expected Response (200 OK):
{
  "success": true,
  "data": [
    {
      "productId": 833,
      "sellerId": 16,
      "sellerName": "Rajesh Kumar Reddy",
      "title": "UltraTech Super Cement OPC 53 Grade (50kg Bag)",
      "sku": "SKU-CEM-OPC53-7971",
      "price": 395.00,
      "mrp": 440.00,
      "stockQty": 800,
      "status": "PENDING"
    }
  ]
}

1.2 Approve Seller Product (Make Product Live on Public Catalog)
--------------------------------------------------------------------------------
Method: PUT (or PATCH)
URL: https://api.hinchmart.com/api/admin/products/{productId}/approve
Example: https://api.hinchmart.com/api/admin/products/833/approve
Headers:
  Authorization: Bearer <ADMIN_JWT_TOKEN>
  Content-Type: application/json

Request Body:
{
  "status": "APPROVED",
  "comment": "Product verified and approved for marketplace catalog."
}

Expected Response (200 OK):
{
  "success": true,
  "message": "Product 833 has been approved and published to catalog.",
  "data": {
    "productId": 833,
    "status": "APPROVED",
    "active": true
  }
}

1.3 Reject Seller Product
--------------------------------------------------------------------------------
Method: PUT
URL: https://api.hinchmart.com/api/admin/products/{productId}/reject
Example: https://api.hinchmart.com/api/admin/products/833/reject
Headers:
  Authorization: Bearer <ADMIN_JWT_TOKEN>
  Content-Type: application/json

Request Body:
{
  "status": "REJECTED",
  "rejectionReason": "Please provide clearer high-resolution product images."
}

2. ADMIN SELLER KYC & ACCOUNT APPROVAL APIS
================================================================================

2.1 Verify KYC Document
--------------------------------------------------------------------------------
Method: PUT
URL: https://api.hinchmart.com/api/seller/onboarding/{sellerId}/documents/{documentType}/verify
Example: https://api.hinchmart.com/api/seller/onboarding/16/documents/PAN_CARD/verify
Headers:
  Authorization: Bearer <ADMIN_JWT_TOKEN>
  Content-Type: application/json

Document Types: PAN_CARD, GST_CERTIFICATE, BANK_STATEMENT, BUSINESS_REGISTRATION

Request Body:
{
  "status": "VERIFIED",
  "rejectionReason": null
}

2.2 Final Seller Account Approval & Store Activation
--------------------------------------------------------------------------------
Method: PUT
URL: https://api.hinchmart.com/api/admin/sellers/{sellerId}/approve
Example: https://api.hinchmart.com/api/admin/sellers/16/approve
Headers:
  Authorization: Bearer <ADMIN_JWT_TOKEN>
  Content-Type: application/json

Request Body:
{
  "status": "VERIFIED",
  "accountStatus": "ACTIVE"
}

================================================================================
5. ORDERS & FULFILLMENT APIS
================================================================================

5.1 List Seller Orders
--------------------------------------------------------------------------------
Method: GET
URL: https://api.hinchmart.com/api/orders?status=CONFIRMED&page=1&limit=20
(or GET /api/seller/orders)
Headers:
  Authorization: Bearer <SELLER_JWT_TOKEN>

5.2 Update Order Status
--------------------------------------------------------------------------------
Method: PATCH
URL: https://api.hinchmart.com/api/orders/{orderId}/status
Headers:
  Authorization: Bearer <SELLER_JWT_TOKEN>
  Content-Type: application/json

Request Body:
{
  "status": "PROCESSING"
}
Allowed Status Transitions: CONFIRMED -> PROCESSING -> SHIPPED -> DELIVERED
