4. TECHNICAL DISCUSSION & ACTION ITEM FOR BACKEND TEAM
--------------------------------------------------------------------------------

Issue: Newly created products are saved in the DB (e.g. ID 790), but do not appear 
in `GET /api/products` or Admin Search.

Root Cause:
1. In `POST /api/products`, Spring Boot `ProductService.createProduct` defaults 
   new products to `active = false` and `status = 'PENDING'`.
2. The query behind `GET /api/products` uses `WHERE active = true AND status = 'APPROVED'`.
3. Because newly created products are `active: false`, the SQL query excludes them 
   from the list returned to the frontend and Admin portal.

Recommended Fix (Choose Option A or B in Spring Boot):

OPTION A (Recommended for Immediate Publishing):
In `ProductService.java` (inside `createProduct` method), default:
  ```java
  product.setActive(true);
  product.setStatus("APPROVED");
  product.setApprovalStatus("APPROVED");
  ```
This matches how Categories and Brands behave and allows products to be 
immediately searchable across the platform.

OPTION B (For Moderated Review Workflow):
In `ProductController.java` / `ProductRepository.java`:
Update `GET /api/products` to accept an optional query parameter:
`GET /api/products?includeInactive=true` or `GET /api/products?status=PENDING`
so the Admin portal can fetch and review pending submissions.
